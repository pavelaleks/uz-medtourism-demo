# Медицинские учреждения Узбекистана — демо

Демонстрационная страница базы медучреждений Узбекистана для медицинского туризма: карта, фильтры, готовые сценарии, сводка по регионам и связи с другими данными.

Подготовил: Алексеев П. В., д. ф. н., профессор Самаркандского государственного университета имени Шарафа Рашидова, pavel.alekseev.gasu@gmail.com

Страница: https://pavelaleks.github.io/uz-medtourism-demo/

Источники: учреждения — © участники OpenStreetMap (ODbL); население — OCHA/UNFPA COD-PS (CC BY-IGO); вузы — открытый справочник (CC0). Записи, похожие на имена частных лиц, публикуются без названия. Индекс готовности — расчётная оценка, а не рейтинг качества медицины.

`data.js` собирается скриптом `tools/prepare.py`.
